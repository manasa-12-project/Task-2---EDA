# Task 2 – Exploratory Data Analysis (EDA)

# Overview

This project focuses on **Exploratory Data Analysis (EDA)** to understand datasets, identify patterns, discover trends, and extract meaningful insights using data analysis techniques.

## 🎯 Objectives

* Understand the dataset structure.
* Identify and handle missing values and duplicates.
* Perform statistical analysis.
* Explore relationships between variables.
* Visualize data to identify patterns and trends.

# Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

# Key Activities

* Data inspection and cleaning
* Descriptive statistical analysis
* Data visualization
* Pattern and trend identification
* Insight generation
